# Week 2 Day 4

## Infrastructure Security Scanning

### Objective

Integrated Checkov into the CI/CD pipeline to scan Infrastructure as Code (Terraform) for security misconfigurations.

### Features

- Automated Terraform security scanning
- Detects insecure infrastructure configurations
- Integrated into GitHub Actions

### Deliverables

- Checkov Scan
- Terraform Security Validation
- Updated CI/CD Pipeline
