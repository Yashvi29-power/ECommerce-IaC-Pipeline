## Software Bill of Materials (SBOM)

### Objective

Implemented automatic Software Bill of Materials (SBOM) generation using CycloneDX.

- Improves software supply chain transparency.
- Integrated into the GitHub Actions pipeline.
- Uploaded as a build artifact.

### Deliverables

- reports/sbom.json
- Updated CI/CD pipeline
