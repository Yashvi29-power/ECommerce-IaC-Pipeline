# Terraform Security Best Practices

## 1. Avoid Hardcoded Secrets
Store credentials in environment variables.

## 2. Enable Encryption
Encrypt S3 buckets and storage services.

## 3. Use Least Privilege
Grant only required permissions.

## 4. Enable Logging
Maintain audit logs for all resources.

## 5. Scan Infrastructure
Use Checkov and TFSec before deployment.
