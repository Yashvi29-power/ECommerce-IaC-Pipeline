# Checkov vs TFSec Scan Results

## Checkov

- Infrastructure Security Scanner
- Large policy library
- Detects Terraform and cloud misconfigurations
- Integrates well with CI/CD

## TFSec

- Terraform focused scanner
- Fast scanning
- Detects Terraform security issues
- Easy to use locally

## Comparison

| Feature | Checkov | TFSec |
|---------|---------|--------|
| Terraform Scan | Yes | Yes |
| AWS Checks | Yes | Yes |
| Azure Checks | Yes | Yes |
| GCP Checks | Yes | Yes |
| CI/CD Support | Excellent | Good |

## Conclusion

Both tools are useful for Infrastructure as Code security. Checkov provides broader policy coverage, while TFSec is lightweight and Terraform-focused.
