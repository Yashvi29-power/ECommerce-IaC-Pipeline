# Checkov and TFSec Notes

## Checkov
- IaC security scanning tool
- Detects Terraform misconfigurations
- Integrates with CI/CD

## TFSec
- Terraform security scanner
- Finds insecure AWS configurations
- Helps enforce best practices

## Importance of IaC Security
- Prevents cloud misconfigurations
- Improves compliance
- Reduces attack surface
